## 3. Scope

**Backend (done on `mvp-2`):** endpoint, upload validation (size, MIME, container, duration), local Whisper Base adapter with pinned/verified model, parser, BR-025 header completion for an empty field, daily quota (`STT_DAILY_LIMIT_REACHED`), one inference per process, typed errors, no audio/transcript persistence or logging.

**Frontend (this increment):** dictation panel on the create page with notice, vocabulary help, permission/support detection, 30 s countdown with automatic stop, 2 MB check, processing state, live region, error mapping to the message catalogue, insertion of `abc_document`, ABC format selection, focus on the field.

**Out of scope / constraints:**
- Appending to a populated field (P02 Q-029 open): dictation is disabled while the field has content.
- Edit page: the delivered HU05 edit page does not edit content, so dictation is not added there (record as a finding).
- No transcript or audio shown or stored after insertion.
