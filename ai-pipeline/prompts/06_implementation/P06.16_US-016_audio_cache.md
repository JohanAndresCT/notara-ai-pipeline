# P06.16 — US-016 Reuse Synthesized Audio (Story Increment)

**Version:** 1.0
**Mode:** Story increment (`P06_implementation.md` v2.0, section 2.2)
**Story:** US-016 / HU16 · P0 / 3 SP — MVP Supporting (enabler)
**Contributor:** TEAM-001 working session — branch `pipeline/mvp2-p00-context`

## 1. What to implement

Synthesized audio is stored once, keyed by kind + spoken text + engine/voice + language; repeated requests are served from storage without calling a provider or using quota.

## 2. Sources

P02 US-016; AC-055-AC-058; FR-038, FR-039; BR-021 · DEC-210 · P05 ADR-008, ADR-012

## 3. Required verification

Backend tests with the fake voice engine (no network), typecheck and build, browser checks on the score detail (ABC, plain text, own vs. others' scores, 375 px), and real-engine/device checks where available.

`US-016_AUDIO_CACHE_IMPLEMENTATION.md`, validation `US-016_AUDIO_CACHE_VALIDATION.md`, implementation log and PROMPT_LOG entries.
