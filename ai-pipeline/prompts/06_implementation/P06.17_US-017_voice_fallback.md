# P06.17 — US-017 Fall Back to a Free Voice (Story Increment)

**Version:** 1.0
**Mode:** Story increment (`P06_implementation.md` v2.0, section 2.2)
**Story:** US-017 / HU17 · P0 / 2 SP (Must by DEC-209) — MVP Supporting (enabler)
**Contributor:** TEAM-001 working session — branch `pipeline/mvp2-p00-context`

## 1. What to implement

With ElevenLabs as primary, any provider error (402, 429, 5xx, timeout, network) switches to `edge-tts`; if both fail the user gets `AUDIO_UNAVAILABLE` and the quota is released. The engine is never revealed; fallback use is logged without personal content. Development uses Edge by default and tests use the fake engine.

## 3. Required verification

Backend tests with the fake voice engine (no network), typecheck and build, browser checks on the score detail (ABC, plain text, own vs. others' scores, 375 px), and real-engine/device checks where available.
